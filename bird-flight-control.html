控制與探索

范兆雄

范兆雄 著

野鳥飛姿，不是盲目連拍的運氣，而是預知形相之後，謹慎決定按快門動機的必然成果。按快門，不該是盲目連拍的開始，而是確切體會時機的刹那。

動機產生行為的驅力，動機愈強，刺激因素不變，行為自有下意識的習慣性反應。野鳥當然有習慣性的姿勢和動作。習慣造成動作行為的重複性，一連串動作是姿勢步驟的累積，因此，動態拍攝，不可能「來不及」按快門，當拍攝對象出現第一、二步驟後，一定會發展到第七、八步驟，故，更不必用連拍完成運氣式的期待。攝影人需學習習慣步驟的次序認知。

野鳥飛行速度影響振次和振幅，吾人或可共同認知以時速五十公里為準，去理解牠們。若以每秒十張的連拍，即知十分之一秒間隔的野鳥羽翅在空間的變化模式。簡單說，預知「等一下」發生的事，是拍飛鳥必備知能。練習拍攝若干次，大小類似的野鳥，便可獲得一致的預知結果，一生適用。

每秒八張的連拍大白鷺飛行，或許看到第二、四、六、八張的姿態是一樣的，飛姿週期已確知，將來則無須連拍這麼多張。看鳥飛行，要用電影慢拍快放的道理體會，八分之一秒，其實是「很長」的時間。吾人拍照，不必企圖一次連拍，得有三張如願成果，一張如實的滿足，便是作品。

第一次接觸特定飛鳥，作者主張盡量使用連拍，以獲取更豐富的反省和檢討內容，以達「視其所以，觀其所由，察其所安」的境地。第二次拍攝，就是熟手，運籌帷幄。

知而後行是攝影屬性。和拍攝對象作知其所以然的認知，再配合同理心，野鳥行為就像自己的行為，感情投射給野鳥之後，密契經驗產生，按快門行為是不知不覺的，作品自生。

野鳥飛姿，何嘗不是，一切食衣住行有關飛姿的問題，善加觀察，一勞永逸地自在拍攝。作者至今依然使用手動調焦，享受必然成功的樂趣；連拍幫我快速捲片，卻不能幫我創造作品的契機。

夜間飛行的神秘姿態（13-1 / 13-2）

13-1 / 13-2

13-1 夜鷹正面衝鏡而來，雙翼展開形成對稱V字，暗黑背景下的光影將鱗片紋路雕塑出金屬質感，是難得一見的夜間飛行正面構圖。

13-2 黃昏下的牛背鷺口銜細枝振翅起飛，正面展翅與懸掛的雙腳形成自然十字構圖，深色背景烘托出純白羽色的張力。

14-2 牛背鷺銜枝側飛，翅膀層次分明，綠林散景自然，是一幅展現築巢行為的動態側面飛行紀錄。

仰角捕捉小型鳥的飛行細節（15-1 / 15-2）

15-1 / 15-2

15-1 從仰角捕捉小型褐色鳥俯衝瞬間，扇形展開的尾羽與上揚的翅膀構成充滿動感的幾何形態，深色背景讓羽毛細節清晰呈現。

15-2 麻雀急速煞停的瞬間，雙翼向後展開，尾羽張開如扇，每根羽毛的紋路與白色羽緣均清晰可見，藍天背景增添了畫面的明亮感。

掠水捕魚與爭鬥展翅（16-1 / 16-2 / 16-3）

16-1 / 16-2 / 16-3

16-1 白鷺俯衝入水捕魚，水花四濺，雙翼在水面上方撐開形成傘狀，魚口已然在握，是難度極高的入水瞬間捕捉。

16-2 大白鷺在霧色灰調背景下大幅展翅，嘴喙張開、蓑羽飛散，展現出鷺鳥領地爭鬥時最戲劇性的姿態。

16-3 白頭翁在綠草間振翅，嘴喙微張，背景的草穗形成柔和的綠色散景，小型鳥類的飛行活力躍然紙上。

高翔的高蹺鴴（17-1 / 17-2）

17-1 / 17-2

17-1 高蹺鴴黑白分明的翅膀在藍灰色水面上構成強烈的明暗對比，粉紅長腳微微收起，飛行路線俐落直接。

17-2 同樣的高蹺鴴從較近距離捕捉，細白頸羽在飛行氣流中微微張開，可見頸部羽毛的細膩質感，背景的水面紋理增添了畫面的空間感。

美麗的鳥，按快門即可獲得，鳥的美麗，卻要精心「設計」和「安排」。攝影者的內在、外在修養，奠定設計和安排的能力基礎。
